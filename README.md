# 章子怡 or 童瑶？

一个 20 张照片的「脸盲测试」：每张照片只回答一个问题——照片里的人是**章子怡**还是**童瑶**。

在线玩：https://zzsqwq.github.io/ziyi-or-tongyao/

## 规则

- 每次进入页面**随机抽 20 张**（章子怡 10 张、童瑶 10 张），顺序也是随机的，所以没有固定的答案可以背。
- 一张一题，选完自动下一张；选错了可以点「← 上一张」回去改。
- 中途不给对错提示，20 张答完统一揭晓：分数、正确率和逐张对照。
- 键盘 `1` / `2` 作答，`←` 返回上一张。

## 这 60 张图是怎么来的

- 出题图从公开网络（百度图片的搜索结果，多为新闻页、百家号、微博等公开页面）抓取，共 166 张候选，
  按「章子怡 / 童瑶 + 写真、红毯、微笑、正脸、高清、礼服、采访、侧脸」等 20 组关键词收集。
- 用 YuNet 做人脸检测，再按双眼关键点对齐，统一裁成 640×800；同一角度、同一比例，避免用构图差异去暗示身份。
- 再从候选里挑出 60 张进池子（每边 30 张）：量化「像不像对方」和「像不像自己」——
  跨人相似度越高越容易被认错，同人相似度太高则会露馅（看得出是同一组片子），所以后者被压低。
- 每次抽 20 张时保持 10:10，这样「我实在分不出来，全点童瑶」这种打法最多也只能拿 50%。

**本仓库不含答案对照表**：哪张是谁的映射编码在页面里，是刻意不列在这里的，免得直接把游戏剧透光。
